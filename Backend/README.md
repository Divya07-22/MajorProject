# Blockchain-Based Fraud Detection System

Advanced fraud detection system combining AI/ML models with Ethereum blockchain and zero-knowledge proofs.

## Features

- 🤖 Multi-model AI detection (Isolation Forest, LSTM, GNN, XGBoost)
- 🔗 Ethereum blockchain integration
- 🔐 Homomorphic encryption for sensitive data
- 📞 Automated voice call verification (Twilio)
- 🛡️ Zero-knowledge proof privacy layer

## Quick Start

### Prerequisites

- Python 3.11+
- PostgreSQL 13+
- MongoDB 5.0+
- Node.js (for Truffle)
- Ganache (for local blockchain)
